# Asset research

Candidate resources only; none have been downloaded or added. Check each pack's current license, price, contents, required attribution, redistribution terms and tournament rules before using it. A pack's page or terms can change; free to download does not automatically mean every use is permitted. Record the author, source URL, license and changes in an asset credits file when a pack is selected.

- [Quaternius — Sci-Fi Essentials Kit](https://quaternius.itch.io/sci-fi-essentials-kit): a possible source of modular sci-fi environments for the arena. Check the current pack details and terms for fit.
- [Quaternius — Modular Sci-Fi MegaKit](https://quaternius.itch.io/modular-sci-fi-megakit): another possible modular environment set. Compare scope and style with the smaller kit.
- [KayKit — Dungeon Pack (legacy)](https://kaylousberg.itch.io/kaykit-dungeon): a stylized 3D dungeon set if the team prefers an ancient Haven aesthetic. The page marks this version as legacy; check for a current version and its terms.
- [Kenney Game Assets All-in-1](https://kenney.itch.io/kenney-game-assets): a broad paid collection, not a required purchase. Check its contents and terms before deciding. Individual free packs may be available separately.

Aim for one coherent art direction rather than mixing every pack. Verify that the chosen file formats import into the team's Godot version, test scale and collision, and avoid committing unlicensed or purchased files whose terms prohibit redistribution.
