# Haven: Bounce Back — Arena

A proposed 3D arena shooter for team Bounce Back's game jam. This is a **planning repository**, separate from the team's existing game. The ideas are starting points for the team to choose and change.

- [Game concept and design](docs/GAME_CONCEPT.md)
- [Game-jam build roadmap](docs/ROADMAP.md)
- [Art and asset research](docs/ASSETS.md)

## Current status

Brainstorming only: there is no playable game or `project.godot` file yet. The planned first playable is an offline arena match against bots; online play and a larger story are later milestones if time allows.

When the Godot project is built, open Godot's Project Manager, choose **Import**, select its `project.godot` file, and import it. Agree on the Godot 4 version with the team before implementation so everyone uses the same editor.
